# Customer survey analysis

## Context
A hospitality client needed driver analysis on 14,000 survey responses.

## What I did
- R.
- Confidence intervals and regression instead of eyeballing charts.
- Clear charts that answer one question each.
- Data cleaning.

## Result
The project pinpointed check-in wait as the top satisfaction driver.
