# Signup funnel analysis

## Context
A edtech client needed step-by-step drop-off analysis of the signup flow.

## What I did
- Web-traffic and funnel events from Google's analytics product.
- Wrote the joins and window functions by hand.
- Tracked how each signup month retained over time.
- Clear charts that answer one question each.

## Result
The project one form change lifted completed signups 14%.
