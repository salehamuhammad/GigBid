# Internal semantic search

## Context
A media client needed hybrid keyword and embedding search over a 1.2M article archive.

## What I did
- An approximate nearest-neighbour index over embeddings.
- Document Q&A.
- HF Transformers.
- Served it behind an async Python web service.

## Result
The project editors found source material 40% faster in a timed study.
