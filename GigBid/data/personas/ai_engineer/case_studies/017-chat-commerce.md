# WhatsApp-free order assistant

## Context
A food delivery client needed an in-app ordering assistant with tool calls to the menu and cart APIs.

## What I did
- Wired the model calls into a stateful graph of cooperating agents.
- Python REST API.
- An in-memory cache and queue backend.
- PostgreSQL.

## Result
The project handled 46% of orders without a human agent.
