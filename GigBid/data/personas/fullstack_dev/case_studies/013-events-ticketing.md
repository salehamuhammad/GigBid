# Event ticketing site

## Context
A events client needed seat selection with live availability.

## What I did
- A component-based single-page interface.
- A JavaScript back end with middleware routing.
- Payment integration.
- NoSQL.
- Pushed live updates to the browser without polling.

## Result
The project sold 12,000 tickets in one launch day without downtime.
