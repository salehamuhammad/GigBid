# Live support chat widget

## Context
A customer support client needed an embeddable live chat with typing indicators and agent routing.

## What I did
- Real-time.
- A JavaScript back end with middleware routing.
- A component-based single-page interface.
- An in-memory cache and queue backend.

## Result
The project handled 3,000 concurrent sessions in load tests.
